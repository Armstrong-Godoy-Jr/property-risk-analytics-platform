# Property Risk Analytics Platform

Does a mitigation action (roof upgrade, defensible space) causally reduce risk
exposure? An end-to-end geospatial data pipeline and causal analysis, built with
production-style data quality practices.

See `docs/PROBLEM.md` for full context on the business problem and methodology.
